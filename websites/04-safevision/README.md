# SafeVision

URL: https://safevision.cmcati.vn/

Đây là danh mục khởi tạo, chưa khảo sát trực tiếp trong lần chuẩn bị này. Xác nhận tên menu và quyền truy cập trên UI trước khi hoàn thiện test. Không coi các tên thư mục là bằng chứng tính năng đã tồn tại.

Mở checklist.csv, sau đó từng thư mục trong features/. Chạy đăng nhập trước, đăng xuất cuối.
